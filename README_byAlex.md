# 精准就业服务平台 - 模块化重构版

## 项目结构

```
精准就业平台-重构版/
├── index.html                    # 主页面模板（HTML骨架 + 脚本引用）
├── README.md                     # 本文件
└── assets/
    ├── styles/
    │   └── main.css              # 全局样式表
    ├── modules/                  # 渲染引擎模块（通用，无需修改）
    │   ├── core.js               # 全局变量初始化、工具函数
    │   ├── student-render.js     # 学生画像渲染（仪表盘、筛选、卡片、弹窗）
    │   ├── jobs-render.js        # 岗位库渲染（岗位卡片、职前通对接、视图切换）
    │   ├── graph-render.js       # 能力图谱渲染（四层结构、技能标签）
    │   ├── student-view.js       # 学生端视图（学号选择、个人主页）
    │   ├── interview-render.js   # 面试模块渲染（题单、辅导、雷达图）
    │   └── init.js               # 应用入口（ESC关闭、CSV导出、动态注入）
    ├── course.js                 # 【班级特有】课程元数据（模块/知识点）
    ├── students.js               # 【班级特有】学生画像数据（成绩/推荐/提升建议）
    ├── eval_embed.js             # 【班级特有】课堂测评嵌入页数据
    ├── jobs.js                   # 【通用】岗位库数据
    ├── graph.js                  # 【通用】能力图谱数据
    ├── zqt.js                    # 【通用】职前通平台对接数据
    └── interview.js              # 【通用】面试题库数据
```

## 快速开始

本项目是基于多agent的精准就业服务平台完整架构设计的程序流程展示demo，可以直接用浏览器打开 `index.html` 即可使用，无需服务器。


## 通用资产说明

以下文件为所有班级共享，通常不需要修改：

- **jobs.js** — 60个ICT行业岗位定义（数字安防/Datacom/云计算/大数据/AI/鸿蒙）
- **graph.js** — 岗位能力图谱四层结构（方向→岗位族→岗位→技能标签）
- **zqt.js** — 职前通平台对接数据（真实职位/课程/认证映射）
- **interview.js** — 面试题库（按维度分类的技术题/项目题/压力题）
- **modules/*.js** — 渲染引擎代码（将数据渲染为页面UI）

## 架构设计原则

- **数据与渲染分离**：数据文件只包含纯数据，渲染逻辑在modules中
- **通用与班级分离**：通用资产跨班级复用，班级数据按需替换
- **零构建依赖**：纯静态文件，浏览器直接打开，无需Node.js/Webpack
- **向后兼容**：保持原有功能完整性，仅改变文件组织方式

## 岗位库自动更新功能

### 功能说明

平台集成了从职前通（zhiqiantong.cn）自动抓取最新职位数据的功能。在岗位库页面点击"从职前通更新岗位库"按钮，系统会：

1. 自动连接本地服务器（需先启动）
2. 从职前通网站抓取最新职位信息（前20个职位）
3. 提取职位详情（薪资、要求、职责等）
4. 智能匹配到本平台的岗位ID
5. 生成新的 `zqt-updated-{时间戳}.js` 文件
6. 弹窗提示用户手动替换原文件

### 使用方法

**第一步：安装依赖**

```bash
npm install
```

**第二步：启动本地服务器**

```bash
npm start
# 或
node server.js
```

服务器将在 `http://localhost:3000` 启动。

**第三步：访问平台并更新**

1. 浏览器打开 `http://localhost:3000`
2. 进入教师端 → 岗位库
3. 点击"🔄 从职前通更新岗位库"按钮
4. 确认更新操作
5. 等待数据抓取完成（约1-2分钟）
6. 更新成功后，按提示将新文件重命名为 `zqt.js` 并替换原文件
7. 刷新页面查看更新后的岗位库

### 手动更新（命令行方式）

也可以直接运行更新脚本：

```bash
npm run update
# 或
node scripts/update-jobs.js
```

脚本会在 `assets/` 目录下生成带时间戳的新文件，如 `zqt-updated-2026-09-15T22-30-45.js`。

### 注意事项

- **需要网络连接**：更新功能需要从职前通网站抓取数据
- **抓取频率**：每次更新抓取前20个职位详情，请求间隔1秒，避免对目标网站造成压力
- **数据匹配**：系统会根据职位标题自动匹配到本平台的岗位ID（如 cl-ops, ai-cv 等）
- **手动替换**：生成的新文件不会自动覆盖原文件，需要用户确认后手动替换
- **备份建议**：更新前建议备份原 `zqt.js` 文件

### 技术实现

- **后端**：Node.js + Express（server.js）
- **抓取**：axios + cheerio（scripts/update-jobs.js）
- **前端**：Fetch API 调用后端接口（assets/modules/init.js）
- **API端点**：`POST /api/update-jobs`
